## AI Model management tool

LM Studio Portable is LM Studio packaged with a PortableApps.com launcher as a [portable app](https://portableapps.com/about/what_is_a_portable_app), so you can run it from any computer. It keeps LM Studio's settings and models portable, leaving no personal information behind on the host machine. [Learn more about LM Studio...](https://lmstudio.ai/)

[Get more portable apps at PortableApps.com](https://portableapps.com/)
